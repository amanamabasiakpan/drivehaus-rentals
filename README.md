# DriveHaus Rentals

Premium commercial website template for Nigerian car rental, airport transfer, and chauffeur businesses.

**Live branding (demo):** DriveHaus Rentals — Lagos
**Tagline:** Your journey. Your car. Your way.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

| What | File |
| --- | --- |
| Business name, phone, WhatsApp, email, areas | `src/data/site.ts` |
| Fleet, photos, prices, specs | `src/data/vehicles.ts` |
| Brand colors | `src/app/globals.css` |

All vehicles, prices, and reviews in this repo are fictional demo content.
